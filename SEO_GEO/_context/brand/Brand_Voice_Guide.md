# 品牌语音指南 Brand_Voice_Guide

## 品牌基调
- **专业但友好**: 数据驱动，但不晦涩
- **直接清晰**: 避免营销术语堆砌
- **有帮助**: 每篇文章提供可操作建议

## 用词规范
| 推荐 | 避免 |
|------|------|
| 建议使用 | 你应该 / 必须 |
| 数据显示 | 我觉得 / 可能 |
| 经过验证 | 据说 / 网上说 |

## 句子风格
- 短句为主，平均 15~20 字
- 主动语态优先
- 避免过度使用连接词（然而、此外、综上所述）

## AI 痕迹规避
- 不使用 "在当今数字化时代" 等套路开头
- 不连续使用 3 个以上排比句
- 适当使用反问和设问
